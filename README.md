# Customer-Churn-Prediction

## Overview

This project is created to test and demonstrate basic machine learning  & Deep lerning skills by building a  Customer-Churn-Prediction prediction model. It focuses on understanding the complete ML,Dl workflow from data handling to prediction.

## ▶️ How to Run

first run model.py <br>

We do not use an ANN directly; instead, we try different machine learning models, such as logistic regression, SVM, and XGBoost, with the assistance of Optuna.
